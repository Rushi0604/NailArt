# Nail Art Box — React Website

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run:
   npm install
   npm run dev
4. Open the local Vite URL shown in the terminal.

## Customize
- Business name: `src/main.jsx`
- Phone/WhatsApp/Instagram: search for `9999999999` and the Instagram URL.
- Location: search for `Your City, India`.
- Prices/services: edit the `services` array.
- Gallery: edit the `gallery` array and replace image URLs with your own nail photos.
- Main styling: `src/styles.css`.

The booking form currently shows a confirmation inside the website. Connect it to WhatsApp, Formspree, EmailJS, or your own backend when you're ready for real booking submissions.
